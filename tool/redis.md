# Redis 开发笔记

## 简介

Redis 是一款开源的内存数据结构存储系统，以其高性能、高并发支持而著称。它不仅能够作为数据库使用，还可以充当缓存和消息队列中间件。由于其数据存储于内存中，因此在读写性能、可扩展性及灵活性方面表现优异。

## 使用 Redis 的优势

- **提升读写速度**：通过将数据保存在内存中，极大地提高了数据处理速度。
- 

- **增强并发能力**：高效管理大量并发请求的能力，使其成为构建高并发应用的理想选择。

## 支持的数据类型

Redis 支持多种数据类型，每种类型都针对特定的应用场景进行了优化：

- **字符串 (String)**：最基本的数据类型，适用于简单的键值对存储。

- **散列表 (Hash)**：用于存储对象，允许字段和字段值之间的映射。

- **链表 (List)**：一个双向链表，支持从两端快速插入或移除元素。

- **集合 (Set)**：无序且不重复的元素集合，支持多种集合操作，如交集、并集等。

- **有序集合 (Sorted Set)**：与集合类似，但每个元素关联一个分数，通过分数来为成员排序。
